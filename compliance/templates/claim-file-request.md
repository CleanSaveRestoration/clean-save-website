# Claim file request (homeowner sends)

Use when we need to see the carrier's estimate, notes or photos to build a supplement, or when a decision is stalled. The homeowner sends this.

---

Subject: Claim [CLAIM #], request for claim file materials

Dear [ADJUSTER NAME],

Please send me the following from my claim file: claim notes, all estimates and bids, measurements and plans, photos, and communications about my claim.

I understand these are generally provided within 15 business days of a reasonable request (WAC 284-30-340(2)). If anything is withheld, please tell me what it is.

Thank you,
[INSURED NAME]
[PHONE / EMAIL]

---

Log it: set `claim.claim_file_requested` to the date sent.
